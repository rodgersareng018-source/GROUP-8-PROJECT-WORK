# GROUP-8-PROJECT-WORK
C++ educational Support Vector Machine project developed by a group of eight members.

## EduSVM: Educational Support Vector Machine

A beginner-friendly, modular Support Vector Machine (SVM) C++ library designed to predict student performance metrics. This project is built collaboratively as a team to demonstrate clean software engineering principles, class knowledge of object oriented programming, automated build testing, and mathematical optimization tracking.

## Getting started
Follow the following steps to set up and run this c++ project locally on your machine.

### Prerequisites 
Before you begin, make sure you have the following installed on your windows machine:
* **Compiler/IDE:** [VS 2022] (https://microsoft.com) (with the "Desktop development with C++") or [ MinGW-w64] (https://mingw-64.org) for GCC/G++.

### Installation setup
1. **Clone the repository**
   Open your Git bash or command prompt and run:
   '''bash 
   git clone http:github.com cd GROUP-8-PROJECT-WORK 
   '''

2. **Generate and build files using CMake**

3. **Complie and build the project**

4. **Run the project**
